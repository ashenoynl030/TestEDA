# PM Skills Dashboard — Team Guide

## What Is It?

The PM Skills Dashboard is an integrated learning tool built into your app that gives your team instant access to **46 professional PM skills** organized by type. It's designed to help product managers discover frameworks, templates, and interactive guidance for common PM work.

**Location:** In the app navigation, click **"PM Skills"** (the book icon)

## Three Types of Skills

### 1. **Component Skills** (20)
Self-contained templates and artifacts for building PM deliverables.

**Examples:**
- User Story (Mike Cohn format + Gherkin acceptance criteria)
- Problem Statement (structured problem framing)
- PRD Development (product requirements template)
- Positioning Statement (market positioning framework)

**When to use:** When you need a template or quality checklist for something you're building.

### 2. **Interactive Skills** (20)
Guided discovery flows that ask questions, adapt based on your answers, and offer smart recommendations.

**Examples:**
- Discovery Interview Prep (prepares you for customer research)
- Prioritization Advisor (frameworks for feature prioritization)
- Feature Investment Advisor (evaluate ROI of new features)
- Director Readiness Advisor (coaching for leadership transitions)

**When to use:** When you need guidance on decision-making or strategy and want AI to ask the right questions.

### 3. **Workflow Skills** (6)
End-to-end processes that orchestrate multiple steps and often reference component and interactive skills.

**Examples:**
- Discovery Process (full customer discovery cycle)
- PRD Development (product requirements process)
- Roadmap Planning (strategic roadmap development)
- Executive Onboarding Playbook (30-60-90 day transition plan)

**When to use:** When you're running a multi-week project and need a structured process to follow.

## How to Use the Dashboard

### Discovery & Search

**Find a skill by keyword:**
1. Click the search box
2. Type any keyword (e.g., "roadmap", "retention", "positioning")
3. See matching skills in real-time

**Filter by type:**
- Click "Component", "Interactive", or "Workflow" to narrow results
- Click "All Types" to see everything

### View Skill Details

1. **Click a skill card** to open the detail view
2. See:
   - Full description (what this skill does)
   - Intent (why this matters and what you'll be able to do)
   - "Best For" scenarios (when to use this)
   - "When to Use" examples (real-world cases)
   - Estimated time (how long it takes to work through)
3. **Click "View Full Skill"** to open the complete skill file in GitHub (includes full framework, templates, examples, and common pitfalls)

### Using Skills in Your Work

#### For Component Skills:
1. Open the skill detail
2. Click "View Full Skill" to see the full template
3. Copy the template or follow the quality checklist
4. Adapt to your context

**Example workflow:**
- Need to write user stories? → Search "user story" → View Full Skill → Copy template → Write stories for your team

#### For Interactive Skills:
1. Open the skill detail to read the overview
2. Click "View Full Skill" to follow the full interactive flow
3. Answer questions one at a time
4. Get context-aware recommendations
5. Choose the option that fits your situation

**Example workflow:**
- Need to decide if a feature is worth building? → Search "feature investment" → Follow the advisor's questions → Get ROI recommendation

#### For Workflow Skills:
1. Open the skill detail for overview and context
2. Click "View Full Skill" to see the step-by-step process
3. Follow the process step-by-step
4. Reference linked component and interactive skills as you go

**Example workflow:**
- Starting a full product discovery? → Search "discovery process" → Follow the phases → Use linked component skills (interview guides, problem statements) as you execute

## Pro Tips

### 1. **Bookmark Skills You Use Often**
After viewing a skill, bookmark the URL so you can quickly jump back to it. Useful for skills you reference regularly (e.g., User Story template).

### 2. **Create Team Workflows**
- Share a workflow skill (e.g., "Discovery Process") with your team
- Assign team members to follow it together
- Reference the linked component skills as you execute

### 3. **Pair with AI Tools**
Copy skill content into Claude, ChatGPT, or other AI tools to:
- Generate examples using a template
- Run an interactive skill flow in conversation
- Customize frameworks for your product

### 4. **Onboard New PMs**
Walk new team members through 3-5 core skills:
- User Story (how you write requirements)
- PRD Development (your process for building products)
- Prioritization Advisor (how you make trade-off decisions)
- Discovery Process (how you learn from customers)
- Finance Metrics Quick Ref (your financial language)

### 5. **Combine Skills for Power**
Most PM projects involve multiple skills:
- **New Feature:** User Story → Feature Investment Advisor → Epic Hypothesis → PRD Development
- **Customer Discovery:** Discovery Interview Prep → Discovery Process → Problem Statement → Opportunity-Solution Tree
- **Product Launch:** PoL Probe → Positioning Statement → Press Release → Roadmap Planning
